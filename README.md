# 🤖 Automação de Atendimento e Vendas para WhatsApp

Robô inteligente desenvolvido em Python para atendimento automatizado no WhatsApp Web. O sistema monitora mensagens recebidas em tempo real, identifica palavras-chave de interesse do cliente e entrega links de produtos digitais e páginas de vendas de forma autônoma.

## 🚀 Funcionalidades
- **Detecção de Mensagens Não Lidas:** Monitoramento contínuo via Selenium WebDriver.
- **Respostas Automatizadas:** Disparo inteligente baseado em palavras-chave pré-configuradas.
- **Suporte a Múltiplos Fluxos:** Configuração modular de gatilhos e mensagens de conversão.
- **Persistência de Sessão:** Mantém o login ativo sem necessidade de escanear o QR Code a cada reinicialização.

## 🛠️ Tecnologias Utilizadas
- **Python 3**
- **Selenium WebDriver**
- **WebDriver Manager**
- **PyInstaller** (para distribuição e empacotamento em `.exe`)
